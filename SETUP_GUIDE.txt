2. Cloudflare D1 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Cloudflare Dashboard
→ Storage & Databases
→ D1
→ Create database

추천 이름:
kenneth-homepage-db

생성 후 D1 콘솔에서 schema.sql 전체를 실행합니다.

3. Cloudflare R2 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Cloudflare Dashboard
→ R2 Object Storage
→ Create bucket

추천 이름:
kenneth-homepage-media

R2 버킷은 공개 설정을 하지 않아도 됩니다.
홈페이지의 /media/... Function이 이미지를 전달합니다.

4. Pages 바인딩 연결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Workers & Pages
→ kenneth-homepage
→ Settings
→ Bindings

D1 database binding:
Variable name: DB
Database: kenneth-homepage-db

R2 bucket binding:
Variable name: MEDIA
Bucket: kenneth-homepage-media

바인딩을 추가한 뒤 반드시 다시 배포합니다.

5. 관리자 비밀번호와 세션 Secret
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Workers & Pages
→ kenneth-homepage
→ Settings
→ Variables and Secrets

Secret 1
Name: ADMIN_PASSWORD
Value: 80981356

Secret 2
Name: SESSION_SECRET
Value: 32자 이상의 임의 문자열

예:
kenneth-2026-session-secret-change-this-9K2m

SESSION_SECRET은 예시를 그대로 쓰지 말고
본인만 아는 긴 문자열로 바꾸는 것을 권장합니다.
