SETTLEMENT IMPORT

정산 엑셀 가져오기

미네르바 원본 정산서를 바로 가져올 수 있습니다. 여러 월의 파일을 함께 선택하면 기존 자료에 추가하고 중복 내역을 제외합니다. 통합관리 엑셀도 지원합니다. 음원 수익월은 정산월 - 3개월로 자동 계산합니다.

카운트 처리 규칙

  1. 원본카운트 > 0: 실제 카운트
  2. 원본카운트 = 0 + 수익 발생: 정산서 보정 카운트로 별도 표시
  3. 원본카운트 미제공: 동일 음원/플랫폼/유통사 순으로 단가 중앙값을 찾아 추정, 최후에는 전체 중앙값 사용
  4. 추정값은 실제값과 합쳐 보이지 않고 추정으로 명확히 구분
